# state_machine_complete

# target
1. 使用状态机实现一个简单的HTML解析器


# description
* 状态​​：系统在特定时间点所处的状况。例如，灯的“开”和“关”。
* ​​事件​​：导致状态发生变化的外部输入或触发条件。例如，“按下开关”这个动作。
* ​​转换​​：定义当某个事件在特定状态下发生时，系统应切换到哪个新状态。例如，在“关”状态下“按下开关”，会转换到“开”状态。
* ​​动作​​：在状态转换发生时可以执行的操作（可选，但非常有用）。例如，在切换到“开”状态时，执行“点亮灯泡”的动作。
